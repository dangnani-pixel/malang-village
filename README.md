# 🍑 말랑마을 케미 테스트 v2

사이트: https://dangnani-pixel.github.io/malang-village/

20개 상황형 질문, 3개 선택지, 4개 취향 축으로 8종 동물 캐릭터를 찾습니다. 각 축은 5개 질문의 평균으로 계산하고, 캐릭터 설정과의 평균제곱근 거리로 가장 가까운 캐릭터를 선택합니다. 가까운 차순위와 균형형 응답도 표시합니다.

업무·친구·연애마다 다른 단짝 두 명, 잘 맞는 이유, 갈등 포인트, 케미 미션을 제공합니다. 추천은 검증된 심리 통계가 아닌 창작 캐릭터 설정입니다.

파일을 함께 보관하고 index.html을 열면 실행됩니다. 서버 전송·답변 저장·분석 추적은 없습니다. GitHub Pages main 브랜치 최상위에서 게시합니다.

검증: 10,000개 응답 표본, 8종 결과 도달, 192개 궁합 조합, 관계별 추천 48개, 이전 질문 및 캐릭터 도감 복귀, 모바일 표시.
